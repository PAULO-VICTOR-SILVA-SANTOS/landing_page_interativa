Recentemente desenvolvi uma landing page interativa inspirada em uma marca de refrigerantes, com foco em experiência do usuário (UX) e animações modernas baseadas em scroll.


💡 Tecnologias e conceitos aplicados no projeto:


🔹 HTML5 (semântico)

*Estrutura organizada com separação clara de seções (hero, cards, nav)

*Uso de boas práticas para acessibilidade e organização do DOM


🔹 CSS3 avançado

*Layout com Flexbox

*Uso de gradientes modernos

*Responsividade com unidades relativas (vw, %, vh)

*Posicionamento absoluto para criação de camadas visuais (efeito “depth”)

*Customização de fonte com @font-face

*Estilização limpa e foco em UI moderna


🔹 JavaScript + GSAP

*Utilização da biblioteca GSAP (GreenSock Animation Platform) para animações performáticas

*Uso do plugin ScrollTrigger para criar animações sincronizadas com o scroll

*Criação de timelines para controlar múltiplas animações simultaneamente

*Efeito de transição fluida entre seções (scroll-based storytelling)


🔹 Animações e UX

*Movimento de elementos (frutas, garrafas, folhas) criando uma experiência dinâmica

*Técnica de parallax visual

*Interação baseada no comportamento do usuário (scroll)


🔹 Organização do projeto

*Separação em arquivos (HTML, CSS, JS)

*Estrutura pronta para escalar e integrar com frameworks futuramente
